# 종목 관리

관리자 → 종목 관리에서 기존 종목을 종료하거나 새 종목을 등록한다. 기준 변경은 기존 행 수정이 아니라 새 ID 등록으로 처리한다. 이름이 같아도 기록은 합쳐지지 않는다.

- 선행: 목표 G열 ID와 모든 회차의 `id:` 헤더 이전 완료.
- 신규 등록: 이름, 개수/시간, 목표, 만점(개수만), 순위 방향, 면제 허용 여부를 입력한다. 서버에서 UUID를 발급하고 행을 추가한다. 기존 회차에는 추가하지 않는다.
- 종료: 해당 ID가 포함된 마지막 실제 회차로 종료한다. 회차에 없던 종목은 최신 실제 회차를 사용한다. 회차가 하나도 없으면 종료할 수 없다.
- 목표/기록/종목 ID 변경 및 행 삭제는 제공하지 않는다. 종료 종목은 이후 기록지 생성에서 제외한다.
- 종목 변경과 회차 생성은 순차로 진행한다. Google Sheets는 읽기와 쓰기 사이의 트랜잭션 잠금을 제공하지 않으므로 동시에 구조를 편집하지 않는다.
- 신규 행 추가 요청은 자동 재시도하지 않는다. 연결이 끊기면 데이터 새로 고침으로 등록 여부를 먼저 확인한다. 중복 클릭 방지를 위해 저장 중 입력을 잠근다.
- 저장은 관리자 API만 허용한다. 엣지 캐시는 현재 콜로에서 삭제하며 다른 콜로는 기존 15분 TTL이 적용된다.

운영 검증은 관리자 로그인 후 기존 기록 조회/수정, 새 종목 등록, 기존 종목 종료, 새 기록지 생성 흐름을 확인한다. 단위 테스트 성공은 운영 계정 권한 검증을 대체하지 않는다.

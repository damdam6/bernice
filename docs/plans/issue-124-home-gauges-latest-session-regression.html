P7 — 홈 화면: 최신 회차 측정 종목 게이지 검증 (7종목 회귀)

damdam6/bernice 브랜치 feat/124-home-gauges-latest-session-regression ← main 라벨 enhancement 2026-07-27

1요약

홈 화면 종목별 달성률 게이지가 최신 회차 측정 종목만 렌더하는지, 종료 종목이 게이지에서 자연 소멸하는지, 7종목까지 늘어나도 목록 레이아웃이 무너지지 않는지를 확인하는 이슈다. 조사 결과 백엔드 좁힘 로직(computeSessionRankings/computeHomeSummary)이 이미 최신 회차 eventKeys만으로 achievementRates를 계산하고 있고 (#130~#138에서 확정), 프론트(buildHomeGauges/Home.tsx)는 이를 필터 없이 그대로 렌더한다. 이슈 본문의 예상대로 코드 변경은 불필요하며, 화면(렌더) 레벨에서 이 계약을 못박는 회귀 테스트 2건만 추가한다.

2현황 분석

  • functions/lib/compute-rankings.ts:74-79 — computeSessionRankings는 그 회차 Session.eventKeys에 해당하는 종목만 헤더 순서로 담는다. 종료 종목이든 아직 시작 전 종목이든 그 회차 eventKeys에 없으면 SessionRankings.events에 아예 항목이 생기지 않는다.
  • functions/lib/compute-home-summary.ts:23-32 — computeHomeSummary의 achievementRates는 rankings.at(-1)!.events(최신 회차분)를 그대로 집계한 것이라, 위 좁힘이 자동으로 승계된다. 이 계약은 이미 functions/lib/compute-home-summary.test.ts의 "혼재 픽스처"·"종료 종목" 테스트 (#134)로 백엔드 단에서 고정돼 있다.
  • src/lib/home-summary.ts:34-42 — buildHomeGauges는 achievementRates를 순서 그대로 매핑만 한다(필터링 없음). 라벨은 events[]에서 key로 조회하되, 종료 종목이 achievementRates에 아예 없으므로 조회 대상 자체가 안 된다.
  • src/pages/Home.tsx:60 — GaugeList는 achievementRates.length > 0일 때만 렌더되고, 내부는 flex flex-col gap-2.5 세로 목록(랭킹 칩의 가로 스크롤과 다름)이라 종목 수가 늘어나도 별도 폴백/스크롤 로직이 필요 없다 — 이는 PRD §08 "🏆 랭킹"/"🏠 홈" 절의 명시적 구분과 일치한다(docs/prd-event-lifecycle.html:305-314).
  • 기존 src/pages/Home.test.tsx는 종목 2개 고정 픽스처만 검증하고 있어, 혼재 (종료 종목 존재) 케이스와 7종목 케이스는 렌더 레벨에서 아직 잠겨 있지 않았다.

3결론

좁힘 규칙은 이미 백엔드(도메인 계산) 계층에서 구현·테스트가 끝났고, 프론트는 그 결과를 그대로 신뢰해 렌더하는 얇은 계층이라 별도 필터링 코드를 추가할 이유가 없다. 남은 리스크는 "백엔드가 이미 좁혀준 데이터를 화면이 실제로 정확히·안 무너지게 그리는가"이므로, 이슈의 완료 조건 두 가지를 화면 컴포넌트 테스트로 직접 검증하는 쪽을 택했다(코드 변경 없이 테스트만 추가 — 이슈 본문의 "코드 변경 최소 예상"과 일치).

4작업 단계

  1. 백엔드 좁힘 로직(computeSessionRankings·computeHomeSummary)과 기존 테스트 커버리지를 확인해 프론트 코드 변경이 불필요함을 확정 functions/lib/compute-rankings.ts, functions/lib/compute-home-summary.ts, functions/lib/compute-home-summary.test.ts
  2. 혼재 픽스처(과거 회차엔 있던 종료 종목이 최신 회차엔 없는 경우) 홈 렌더 테스트 추가 — 게이지 목록에 종료 종목이 나타나지 않고 현역 종목만 렌더됨을 검증 src/pages/Home.test.tsx
  3. 7종목 픽스처로 게이지 목록 레이아웃/구조 회귀 테스트 추가 — 7행 모두 렌더, achievementRates 순서·라벨·달성 카운트 그대로 유지, 뒤 섹션(바로가기)도 밀려나지 않음을 검증 src/pages/Home.test.tsx
  4. npm run test(vitest 전체) · npm run build(tsc + vite build) 그린 확인

# 회차별 목표 이력

같은 측정 방식에서 목표 수치만 달라지면 종목 ID를 유지한다. 측정 방식이나 단위·만점·정렬 방향이 달라져 기록을 직접 비교할 수 없을 때는 독립 종목을 사용한다.

선택적 `목표 이력` 탭의 A:C 헤더는 `적용 회차 | 종목 ID | 목표`다. 종목 ID는 목표 탭 G열을 참조한다. 적용 회차는 실존하는 날짜 탭 이름이다. 같은 종목·적용 회차 조합은 한 번만 등록할 수 있다. 필요하면 D열에 종목명 조회 수식을 두어 운영 시 읽기 쉽게 만들 수 있으며 파서는 A:C만 사용한다.

목표 탭 B열은 최초 기준을 보존한다. 이력의 목표는 해당 회차부터 다음 변경 전까지 적용된다. 과거 기준을 바꾸려고 B열을 덮어쓰지 않는다. 목표 이력은 현재 Google Sheets에서 관리하며 관리자 화면의 신규 종목 생성은 기존과 동일하다.

예시: 동일 ID의 셔틀런 기본 목표가 `1:17`, 후속 회차의 변경 목표가 `1:15`이면 이전 회차 달성 판정은 77초, 변경 회차부터는 75초를 사용한다. 기록과 개인 최고기록·추이는 같은 ID에 연결된다. PB 달성 여부는 최고기록을 세운 회차 기준이다.

API `events[].targetHistory`는 선택적인 `{fromSessionDate,target,targetValue}[]`다. 랭킹·홈 달성률·개인 추이와 PB는 기록 회차의 목표를 사용한다. 랭킹 안내는 선택 회차 기준, 종목 관리/목록은 최신 회차 기준이며 개인 추이의 목표선은 회차별로 변한다. 이력이 없는 시트와 API 응답도 호환된다.

운영 이전은 백업 후 동일 종목 여부를 확인하고, 기존 ID 재활성화·회차 헤더 연결·이력 추가를 함께 적용한다. 사용 중인 점수 열이나 과거 기록을 삭제하지 않는다. 불필요해진 정의는 참조가 없음을 확인한 뒤 정리한다. 변경 후 원래 회차의 점수·랭킹·PB를 비교하고 읽기 캐시를 새로 고친다.
